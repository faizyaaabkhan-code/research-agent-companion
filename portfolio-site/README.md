# Faizyaab Khan — Portfolio Website

A responsive static portfolio for AI-powered product visuals, cinematic content, and e-commerce operations.

## Deploy
- Vercel project root directory: `portfolio-site`
- Framework preset: Other / static site
- Build command: none
- Output directory: leave empty / default
- No environment variables required

## Before public promotion
1. Replace the concept cards with actual work samples and working video links.
2. Add a real product-page audit with before/after screenshots and accurate notes.
3. Verify the contact email and Upwork profile URL.
4. Review all claims and add tool names only if you can use them independently.

The first four project cards are project briefs/placeholders, not claims of completed client campaigns. Do not market them as completed work until you create and replace them with evidence.
